No comparison pricing is displayed. Recorded as a constraint for future work.
Participation Requirements §2(b)Official text

This is the single biggest constraint on affiliate product pages. A site may show prices only where Amazon itself serves the pricing, or where the figures come from the official API, and any displayed price needs a timestamp and a disclaimer. This site therefore links out to Amazon and states plainly that the price on Amazon is the price that applies.

Automation limits — the Agent Terms

IDRequirement SectionSource
A1An 'Agent' — any software taking autonomous or semi-autonomous action — must identify itself in the HTTP user agent as 'Agent/[agent name]'.
This is the binding constraint on full automation of Amazon data collection.
IP Licence, section 4 Agents (a)–(c)Official text
A2An Agent must not conceal that its access is automated, must not mimic human interaction patterns, must not solve or bypass CAPTCHAs, and must not circumvent blocking measures.IP Licence, section 4(c)Official text
A3Do not use Special Links or Program Content to develop machine learning models without prior written approval.Participation Requirements §5Official text
A4Do not use data mining, robots or similar data-gathering and extraction tools on Program Content beyond what the licence allows; use Creators API / PA API instead.IP Licence §1Official text
A5Respect Creators API / PA API rate limits (calls per second) and the 40 KB request limit.IP Licence §2(j)Official text

Why this project does not "fully automate" data collection. Amazon's Agent Terms define an Agent as any software taking autonomous or semi-autonomous action, require it to identify itself in the user agent as Agent/[agent name], forbid disguising automated access, and forbid solving or circumventing CAPTCHAs. A platform that silently scrapes the storefront at scale would breach those terms. The honest build is: automate generation, verification and publishing; take data from official pages under the licence; and move to the official API for anything volume-based.

Commission rates

Not verified, therefore not published. The official rate card at https://affiliate-program.amazon.com/help/operating/schedule requires an Associates login and could not be read. Amazon's public marketing page states only 'Earn up to 10% in associate commissions'.

The only commission claim this site will repeat is Amazon's own public marketing sentence: “Earn up to 10% in associate commissions from qualifying purchases and programs.” (Associates Central).

Anything more specific — for example a category-by-category percentage — must be read from the rate card inside an Associates account and recorded here with its date. Reporting a number from a blog would not meet this project's own standard.
