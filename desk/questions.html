Q-T50-01

Which three products did the brief actually mean?

open

What we know. Each supplied link resolves, reproducibly, to one live Amazon listing: B0CDY277D3, B09B7SB46R and B08DKYBTPH. This project has re-read them on four separate dates (2026-11-13, 11-14, 11-15 and 11-16) and the destination has been identical every time. An unknown code on the same short-link service does not return a product, so the codes are honoured lookups rather than ignored tokens.

What is missing. No public Amazon document binds a link.amazon short code to a product. The codes are nine characters and an ASIN is ten, so the token itself is not an ASIN and cannot be decoded from outside the account that minted it.

How to find out. Open each of the three supplied links while signed in to the Associates account the links were created in, and record the ASIN from the resulting page or from the account's own link report.

Q-T50-11

How often should the official sources be re-read?

open

What we know. This pass re-read every load-bearing source on 2026-11-16 and found one drift: the 26-quart Emeril listing's stored Amazon title is no longer the title Amazon serves. The program policies page states its own update date (2026-04-14) and the Operating Agreement states its (2025-10-15), so drift is detectable when a page states a date.

What is missing. A decision on cadence, and a scheduled runner to enforce it.

How to find out. Owner sets the cadence; a GitHub Actions schedule can then run the existing verifiers and fail on drift.

Q-T50-02

What is the Associates tag for this project?

answered

What we know. The owner supplied the tracking ID shopnow047c-20 in the brief. Since PR #160 (T61) it is on every product button this site writes, applied by the policy-guarded link builder. The five supplied short links do not carry it: they are Amazon's own redirects, and no resolved URL carried a tag when re-observed on 2026-11-19.

What is missing. The tag itself. It is an account credential, so it cannot be looked up, guessed or inferred - inventing one would attribute sales to a stranger's account.

How to find out. The account holder reads it from Associates Central and supplies it. There is no other route.
