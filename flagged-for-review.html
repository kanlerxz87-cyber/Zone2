F-01 · Code B04G1MEwY is not a valid ASIN format

Severity: high (product cannot exist under this identifier) · Status: open

The code is 9 characters. Amazon defines ASIN as a 10-character/10-digit code.

Sources: Associates help — "ASIN is the 10-digit code" · Amazon Selling — "unique 10-character alphanumeric code"

Sources: Associates help · Amazon Selling

F-03 · Code B00hJ57DV is not a valid ASIN format

Severity: high · Status: open

9 characters vs. the required 10.

Sources: Associates help · Amazon Selling

F-04 · All 18 official product-page URLs return HTTP 404

Severity: high · Status: open

Each code was checked on six marketplaces (amazon.com, .co.uk, .de, .in, .ca, .co.jp). Every response was Amazon's "Page Not Found". Full matrix: Products → per-marketplace checks.

Examples: amazon.com/dp/B04G1MEwY · amazon.co.uk/dp/B02NbDxp3 · amazon.co.jp/dp/B00hJ57DV

F-05 · Official Amazon search returns "No results" for all three codes

Severity: high · Status: open

Site search on amazon.com found no listing matching any of the three codes.

Sources: search B04G1MEwY · search B02NbDxp3 · search B00hJ57DV

F-06 · Supplied link.amazon/<code> URLs fall back to unrelated pages

Severity: high · Status: open

Each supplied short link redirected into an unrelated Amazon page with plpRedirect=mhFallback instead of opening a product for the code. link.amazon/ root and /robots.txt returned HTTP 403.

Sources: link.amazon/B04G1MEwY · link.amazon/B02NbDxp3 · link.amazon/B00hJ57DV

F-07 · No product attributes confirmable → all product data cells blank

Severity: high (blocks marketing copy) · Status: open

Name, price, rating, review count, category, BSR, availability, and per-product commission rate are left blank on every page because no official source confirms them. This is intentional: the project rule forbids inference.

Basis: search returns no results · product page 404

F-08 · Per-product commission rate unknown (category unknown)

Severity: medium · Status: open

Amazon's rate card assigns fixed rates by product category. Because P1–P3 categories are unknown, their rates cannot be determined. Program-level rates are published on the Analysis page.

Source: Standard Commission Income rate card

F-09 · Commission Income Schedule requires Associates sign-in

Severity: low · Status: open

Fetching https://affiliate-program.amazon.com/help/operating/schedule redirected to an Amazon sign-in page (observed 2026-11-13), so the personalized schedule could not be captured. The public category rate card was used instead.

Source: Commission Income Schedule (sign-in)

F-10 · Creators API access blocked until Associates account qualifies

Severity: medium (blocks automation) · Status: open

Automated product research requires an accepted Associates account, at least 10 qualifying sales in the past 30 days, registration through Associates Central, and generated credentials. None exist for this project yet.

Source: Creators API — Introduction · Register for Creators API

F-11 · PA-API 5 is deprecated (legacy integrations fail)

Severity: medium · Status: open

Any remaining Product Advertising API 5.0 integration receives HTTP 403 AccessDeniedException. This project's architecture targets the Creators API only.

Source: PA-API 5 Deprecation Notice

F-12 · No Associates Tracking ID supplied → no commission-bearing links

Severity: medium (blocks monetization) · Status: open

The official link format requires tag=YOURASSOCIATEID. No Tracking ID was provided in the brief, so links cannot be tagged and clicks cannot be attributed.

Source: How do I build a simple text link

F-13 · Repository baseline contained no product data or code

Severity: low · Status: open

At baseline (f577167) the repository held a single file: README.md with the text # Zone2. The brief referenced a "full list of requirements" and product links, but no product list, data, or code existed in the repo to reconcile against.

Source: github.com/kanlerxz87-cyber/Zone2 · review: docs/repo-review.md

How to clear these flags

  1. Provide valid 10-character ASINs or corrected product URLs → clears F-01…F-07 (and F-08 once category is visible).
  2. Enroll in Amazon Associates and obtain a Tracking ID → clears F-12 and enables tagged links.
  3. Reach ≥10 qualifying sales in 30 days and register the Creators API → clears F-10.
  4. Drop any legacy PA-API 5 integration → addresses F-11.
  5. Sign in to Associates Central to capture the personalized schedule → clears F-09.
  6. Add the original requirements document to the repo → clears F-13.
