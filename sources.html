Which claims these sources cannot support

Stated plainly, because a long source list can imply more coverage than it has:

  • No source here can identify the three supplied codes. Amazon's help page stating that an ASIN is 10 characters is what proves a 9-character token cannot be one — it is a rule, not a lookup. The lookup itself needs an authenticated Creators API call, which this workspace does not have.
  • No source here fixes the commission band for a specific ASIN. Table 1 publishes "Kitchen 4.50%" and "Home 3.00%" as separate bands; which applies to these three listings is a catalog fact, not a published one.
  • No source here establishes price, rating, review count, BSR or availability for the three listings in a form this site is allowed to republish (see the Program Policies price rule, S02).
  • The manufacturer pages are not Amazon. Where a manufacturer page and an Amazon listing disagree — the 8 Qt power figure and the Emeril preset count — both values are shown and flagged; neither is resolved by preference.
