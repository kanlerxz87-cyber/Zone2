Suggestions & Decision Log

Reviewable suggestions for improving the site. No suggestion is implemented until someone reviews the options and chooses a path. Statuses: Proposed → Under Review → Chosen → Implemented → Blocked. Each suggestion links to its evidence (flags, sources, pages) so a reviewer can decide before anything changes.

Affiliate disclosure (required by the Amazon Associates Operating Agreement §5): As an Amazon Associate I earn from qualifying purchases.

How to use this page

  1. Read each suggestion — the description, why it matters, and the evidence it rests on.
  2. Compare the options — each suggestion lists concrete paths (do it / do it differently / defer), with pros and cons.
  3. Choose a path — a reviewer marks one option "Chosen" and sets the suggestion to "Chosen".
  4. Implement — once chosen, an implementer moves it to "Implemented" and records what changed.
  5. Blocked items stay open — anything that needs owner input (ASINs, Associates tag, Creators API access) stays "Blocked" until that input arrives.

Nothing here is published as a product claim. All figures trace to official sources or are left blank and flagged. The full flag register is at pages/flags.html; the reader-facing dashboard summary is on Flagged for Review.
