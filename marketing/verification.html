How these pages were verified

The method, the exact pages used, and the counts. This page is generated from the same data file as the articles, so the numbers cannot drift away from them.

Method

1

Read the official page

Each product's manufacturer page and its Amazon listing were fetched live on 2026-11-14. Values were copied from the page text, not from a search snippet or a third-party review.

2

Record the quoting text

The specification block wording is preserved in the rows above so a reader can find the same sentence on the same page.

3

Refuse to interpolate

If a page states a range, the range is printed. Unit conversions that the page itself does not give are not performed; where the manufacturer gives both units, both are shown.

4

Publish disagreements

Two official statements that conflict produce a CONFLICT row carrying both sources. Nothing is averaged.

5

Withhold what policy forbids

Prices and ratings are withheld by policy, not merely absent.

Links are not monetized

No Amazon Associates ID is configured for this project, and inventing one is prohibited. Every outbound product link here is therefore an inert preview link produced by the project's link builder, marked rel="sponsored nofollow" and labelled as non-earning. Before publishing, the owner must set the Associates ID; the builder will then emit a properly tagged Special Link instead, and the "preview link" labels disappear automatically because they are driven by that same configuration.
