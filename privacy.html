Privacy & measurement

Measure the page. Not the person.

Implementation status checked 19 November 2026. This notice describes actual code and hosting boundaries, not a certification of legal compliance.

Production status: The GitHub Pages site has no connected analytics collector. Its client configuration is disabled: no browser event is sent or queued for later collection. The self-hosted service is implemented and tested, not provisioned on a production host.

What the self-hosted counter is designed to collect

Once it is deliberately deployed and enabled, it counts page loads, direct product-link clicks and the disclosure strip entering at least half of a browser viewport. It stores a server-assigned UTC day, registered page path, event name and, where applicable, a static product key or disclosure position. These are raw event counts, not unique people, eligible Amazon Sessions or proof that someone read the disclosure.

The client sets no cookie, writes no analytics data to browser storage, generates no visitor/session identifier, sends no referrer or query string and does not fingerprint a device. It honors Global Privacy Control and Do Not Track. The application suppresses HTTP access logs and stores daily aggregates rather than individual requests. A host/reverse proxy may independently handle IP addresses; that must be configured and reviewed before production activation.

Retention and delivery limits

The implemented default is a rolling 90 days for event/report data. Purging runs on ingestion/export and via a documented scheduled command. The counter is best effort: blocked scripts, unavailable endpoints, opted-out browsers and filtering cause undercounts; sophisticated bots can cause overcounts. Origin checks and a global budget do not authenticate human visitors. No unique-session or conversion rate is inferred.

Orders and searches are different data sources

Purchase/order data can only enter through an authorized Associates export; query performance can only enter through an authorized Search Console export that has been reviewed for personal information. Browser events cannot claim either. Each import records the official source URL, channel, period, import time and SHA-256 of the supplied normalized file. No real export is available here. Amazon · Program Policies · Google · Search Console performance.

The optional review draft

The suggestions page stores choices in this browser only when “Save review draft” is pressed. Its key is counter-notes-review-v1. This functional storage is not analytics, is not sent to a server and does not approve a change. “Clear draft” removes it. Export produces a local JSON file. Do not enter personal information.

GitHub and Amazon

GitHub states that Pages logs visitor IP addresses for security, regardless of sign-in status. That hosting behavior is separate from this site’s own counter. GitHub · Pages hosting.

Amazon receives requests when you follow its links and applies its own policies. We do not collect your Amazon login, cart or order information. Product links remain direct; they are not silently opened or routed through an analytics redirect.

Before collection is enabled

Provision an owner-controlled HTTPS endpoint, review lawful basis/consent and the operator notice for the applicable jurisdictions, disable or appropriately manage host-level logs, verify retention and test persistence without production test clicks. A cookie-free design alone does not settle privacy-law obligations. Review the hosting proposal.
