Method

How the data on this site was obtained, and the rules that decide what gets published.

1. Resolve the links

The three supplied links are opaque short links. Each was followed and the redirect target recorded, which yields the ASIN. The ASIN is what identifies the product; the short link does not contain it.

Finding. None of the three resolved URLs carried an Amazon Associates tag= parameter. Without a tracking ID, clicks cannot be attributed to an account. The site therefore links to the canonical product pages and does not invent a tag. See the Flagged for Review page.

2. Capture from official pages only

A value is captured only from an official page: the Amazon product page for that exact ASIN, or the manufacturer's own product page for the model number printed on that listing.

  • Every value is stored with its own source name and URL. A value without a URL is not stored as a fact.
  • Where the manufacturer and Amazon disagree, both values are stored as separate rows, each with its own source, and marked Conflict.
  • Where only a non-official source has a value, the row is marked Unverified and the value is left blank.

3. Decide what may be published

Capture and publication are separate decisions. Several things were captured for the audit trail but are deliberately not published:

CapturedPublished? Why
PriceNoAmazon permits price display only where Amazon serves the pricing or it comes from the official API, and requires a timestamp plus a disclaimer.
Star ratingNoRatings are storefront-specific for the same ASIN, so a single figure would mislead.
Review countNoSame reason; counts also drift continuously.
Stock statusNoChanges by the minute.
Commission rateNoThe official rate card requires an Associates login and was not readable.
Wattage, capacity, dimensions, model number, certification, warranty YesStable manufacturer specifications, each with a named official source.

4. Verify mechanically, not by eye

scripts/verify.py runs on every change and fails the build when:

  • a fact row has no source URL;
  • a source URL is not https;
  • a row claimed as verified has no source;
  • an internal link in the generated site points at a file that does not exist;
  • a page is missing the affiliate disclosure;
  • a page prints a price, which this project does not permit.

The rule is simple: if the checker cannot confirm it, the site does not claim it.

5. Known limitations, stated plainly

  • Amazon pages render inconsistently to automated fetches. Some captures returned only page chrome. Where the US page body did not render, the same ASIN's page on another Amazon storefront was used to read the product-information block, and the manufacturer was used for specifications. This is disclosed per product.
  • No product was tested. This project has not handled any of the three appliances. Nothing here is a performance claim.
  • Capture is a single point in time. The dataset records 2026-11-13. Amazon requires site content to be recent — generally within 60 days — so a re-capture is due by roughly 2027-01-12.
  • Non-official sources were used only to find official ones. They are listed, with the reason for rejection, in data/sources.json.
