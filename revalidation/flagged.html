RV-01 · The supplied codes are not ASINs, but the links are not random either medium

Each code is 9 characters and amazon.com/dp/<code> returns Page Not Found, so no code addresses a catalogue record. However each link.amazon URL carries a distinct, stable, per-link source token and resolves to one consistent product each time.

Disposition: Both halves published. The prior 'arbitrary fallback' reading is corrected.

RV-02 · No Associates tag on any resolved destination high

None of the three resolved destination URLs contains a ?tag= Associates ID. Under OA §1 the tagged link format is required for a Special Link, so as supplied these links cannot be relied on to attribute commission.

Disposition: Flagged. Owner should generate tagged links from SiteStripe or the API.

Sources: https://affiliate-program.amazon.com/help/operating/agreement

RV-03 · The code-to-product mapping is observed behaviour, not documented intent medium

The mapping (B04G1MEwY to B0CDY277D3, B02NbDxp3 to B09B7SB46R, B00hJ57DV to B08DKYBTPH) is reproducible but no public Amazon document binds a short code to a destination ASIN. It is therefore evidence of behaviour rather than proof of intent.

Disposition: Products are presented as 'the product each link resolves to', never as 'the product you selected'. Owner should confirm in Associates Central.

Sources: https://affiliate-program.amazon.com/help/operating/agreement

RV-11 · The per-request attribution token rotates between days; the destination does not low

Each link returns a distinct per-link token of the form btn_ref=srctok-<16 hex>. The three tokens differ from each other and are identical on a same-day re-fetch, but they differ between 2026-11-13 and 2026-11-14 for the same link, while the destination ASIN did not change on any fetch across five sessions and two days. Measured independently by session 0a3dff48 on 2026-11-14.

Disposition: Recorded so that token rotation is not later mistaken for destination instability, and so that the token is not used as a stable identifier of a link. The destination ASIN is the only stable identifier.

Sources: https://www.amazon.com/dp/B0CDY277D3 · https://www.amazon.com/dp/B09B7SB46R · https://www.amazon.com/dp/B08DKYBTPH

RV-12 · Price, ratings, review counts and stock status are visible on the official pages but are withheld by policy low

The no-price rule on this site was originally described as a response to values that could not be verified. That was not the real reason. Re-fetching the three destination pages on 2026-11-14 shows list prices, star ratings, review counts and stock status plainly present on the official Amazon pages. They are blank here because Program Policies §6(a), §6(t) and §6(y), and the IP License, require that kind of Program Content to come from Amazon-served links or the Creators API, and §6(t) bars customer reviews and star ratings outright unless obtained through the API.

Disposition: Stated accurately now, so a reader cannot mistake a policy decision for a verification failure. The blank cells remain blank.

Sources: https://affiliate-program.amazon.com/help/operating/policies · https://www.amazon.com/dp/B09B7SB46R
