## Scope and evidence standard

This is the current release record, not a blanket claim that all historical research was re-verified.
Changed publication source/data/templates were inspected; current factual product rows have dated official
sources. Historical namespaces, dates, flags, decision IDs and source records are preserved. The deployment
packager adds an archive notice, prominent repeated disclosure, sponsored product links and `noindex` to
old evidence/prototype pages rather than deleting or quietly re-dating them. Self-canonicals identify each
real document; they do not misrepresent unrelated audits as duplicate home pages.

An official listing or manufacturer statement is evidence of **what that page says**, not our independent
product test or certification. Prices, ratings, review excerpts, availability, popularity, sales forecasts,
conversion scores, implied hands-on use and invented personal bylines are not published by this release.
An unknown value stays blank with an explicit unverified reason. An observed redirect is never confirmation
of intended product identity or Associates attribution. Old snapshots must not be read as current state.

### Pages source-setting prerequisite corrected before merge

Fresh official [GitHub Pages REST documentation](https://docs.github.com/en/rest/pages/pages#update-information-about-a-github-pages-site)
was read (update section): a settings update requires **Pages write AND Administration write** and an
appropriate repository role; success returns **204 No Content**, not a Pages JSON body. Therefore the
planned main-only PUT was removed **before it ever executed**. A token's `pages:write` deployment
permission is not administrative authority. The deploy job only reads/reports the actual source mode,
warns if legacy is still enabled, and uses the already working artifact-deploy Action. It does not retry
an unauthorized settings write or claim a successful switch.

This is **CN-08, open**: a qualified repository administrator must select GitHub Actions as the source
for sole-publisher assurance on future pushes. Current artifact deployment and its live verification are
separate from this administrative gate. No credentials or manual answer are solicited in the session.
