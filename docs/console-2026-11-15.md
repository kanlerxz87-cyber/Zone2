## The central finding

**The public site is an internal QA dashboard wearing a marketing costume.** The root landing page opens with the
client's own requirement list, verbatim: *"The job. Build an affiliate marketing platform that researches
products, finds trending and high-converting niches, analyzes pricing…"*. Its headline figure strip reports the
project's audit state (`3 of 3 Supplied links that resolve…`, `0 of 3 Brief product mappings confirmed by an
official Amazon document (F-03)`, the count of items on the flag register). Its navigation leads with
Verification, Sources, Flagged, Requirements & Review.

That is why it reads as machine output — not because the sentences are badly written, but because every one is
about the site rather than about the reader's problem. The fix is not a warmer tone; it is having something to
say in the first sentence.

## Sources: how they were verified

Every source below was fetched live on 2026-11-15 by this session; the register holds 31 rows, `C-01` through `C-31`. Three classes, kept strictly apart:

- **official** — Amazon Associates Operating Agreement and Program Policies (including the Participation
  Requirements and the Standard Commission Income Statement Table 1), the Application Review Process page, the
  Creators API introduction, the ASIN link-format help page, Google Search Central's spam policies and
  generative-AI guidance, and the FTC Endorsement Guides. Only these can settle a program rule.
- **observed** — the three supplied `link.amazon` links and the pages they resolve to. Evidence about the
  artefact; never used to state a rule or a product attribute.
- **control** — requests made on purpose: an unknown 9-character code, and a valid 10-character ASIN, both
  passed to the same short-link service.

Controls reproduced: `link.amazon/B00TEST12` → 404; `link.amazon/B0CDY277D3` (a real ASIN) → the identical 404,
so the service does not accept ASINs at all. New observation: both were finally served from `amzlinks.in`.

Restrictions honoured: no product price is printed anywhere in this namespace, no star rating appears, and no
performance figure (clicks, conversions, earnings) is estimated — none can exist without an Associates account.
