Why none of this can run here yet

GitHub Pages is a static site hosting service that takes HTML, CSS, and JavaScript files straight from a repository on GitHub, optionally runs the files through a build process, and publishes a website.

IN-16 — What is GitHub Pages?

That sentence is the whole problem. A self-hosted endpoint needs somewhere to run, and a GitHub Pages site has no such place. Recorded as IF-08 rather than worked around, because the three honest options differ in cost and in what they are allowed to store.
