What this log is for

A redirect is easy to observe and easy to over-read. So each row records not just where the link went but the session and shuffle tokens on the response, which is what lets a reader tell a stable destination from a per-request artefact — and lets the next session compare like with like.

No. A bare request to a known-good ASIN returns the same marker, so its presence says nothing about whether a link fell back. This reproduces the control already recorded in the repository's README; it is re-run here because the argument depends on it.
