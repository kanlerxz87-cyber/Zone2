What we know, and what nothing here can tell you

10 questions standing between the current state and a defensible decision. Every answer field is empty on purpose: an open question with a filled-in answer is a guess wearing a label.

Why every answer is blank. Two of these could be filled in by inference, and both would be wrong to fill in. We know where each link goes; we do not know what was meant. We know no tag is visible; we do not know whether one is applied downstream. A gate in this namespace fails the build the moment an open question acquires an answer, so the temptation is removed rather than resisted.

What is already settled, for contrast

  • Each submitted token is 9 characters, and an ASIN is defined as 10 (IN-03).
  • Each of the five links resolves to one live Amazon product page (IN-09 · IN-12 · IN-13).
  • An unissued code of the same shape returns a 404, so the codes are honoured lookups (IN-14).
  • No resolved URL carries a tag= parameter (IN-01 · IN-03).
  • This host cannot run server-side code (IN-16).

Five settled facts, 10 open questions. The settled ones are measurements; the open ones are all about intent, identity or a decision only the owner can take.
