# Zone2 — Amazon affiliate research workspace

A static, GitHub Pages-ready executive dashboard for organizing three Amazon product references supplied by the project owner. Product metadata and commercial performance are deliberately left blank until checked against an official source.

## Preview locally

Open `index.html` in a browser, or serve the repository root with any static HTTP server. No build step, JavaScript package, API key, or backend is required.

## Pages

- `index.html` — executive summary and product reference inventory.
- `categories/product-research.html` — source-first product research queue.
- `categories/content-studio.html` — content workflow and compliance checklist.
- `categories/campaigns.html` — click/conversion measurement status.
- `flagged-for-review.html` — explicit list of unresolved source and implementation issues.

## Verification limits

The supplied strings are linked exactly as submitted. Each suffix is 9 characters long; the intended identifier, redirects, and listing content could not be independently checked in this environment. No product identity, pricing, rating, review count, trend, competition, commission, or conversion claim has been inferred. Those fields are blank and flagged. The site is an honest, static workspace—not a connected product-research agent or live affiliate tracking system.

See `COORDINATION.md` for the task log, source references, verification performed, and irregularities. Policy links are provided for manual review; no policy interpretation is represented as newly verified here.

## GitHub Pages

The repository is static and can be served from the repository root by GitHub Pages. Enable Pages for the repository's `main` branch/root in GitHub settings after the change is merged. This branch does not itself configure or confirm a Pages deployment.
