3. How to record a decision

  1. Open console/data/decisions.json in the repository.
  2. Find the row for the proposal you have decided on, under "sheet".
  3. Set "choice" to the letter of the option you want (A, B or C), add a short "note" if you want, and set "decided_by" and "decided_on".
  4. Commit the file. The next build re-renders the board with your choice shown on the row and the state changed from proposed to approved.
  5. Or simply tell the agent: "approve P-01 option A". The agent records it here and the board updates on the next build.

Rules

  • An empty "choice" means no decision has been made. It is never read as approval and never read as rejection.
  • A proposal cannot move to implemented until it has an approved choice or the owner has said so explicitly in another channel and the agent has recorded it here.
  • Rejections are recorded too, with a note, so the same proposal is not raised again next session.
  • This file does not move, renumber or re-own anyone else's register. It indexes them.
