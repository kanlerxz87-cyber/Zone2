Q-T50-01

Which three products did the brief actually mean?

open

What we know. Each supplied link resolves, reproducibly, to one live Amazon listing: B0CDY277D3, B09B7SB46R and B08DKYBTPH. This project has re-read them on four separate dates (2026-11-13, 11-14, 11-15 and 11-16) and the destination has been identical every time. An unknown code on the same short-link service does not return a product, so the codes are honoured lookups rather than ignored tokens.

What is missing. No public Amazon document binds a link.amazon short code to a product. The codes are nine characters and an ASIN is ten, so the token itself is not an ASIN and cannot be decoded from outside the account that minted it.

How to discover it. Open each of the three supplied links while signed in to the Associates account the links were created in, and record the ASIN from the resulting page or from the account's own link report.

Q-T50-02

What is the Associates tag for this project?

open

What we know. None of the three resolved URLs carries a tag parameter. Amazon's documented qualifying link format requires one: http://www.amazon.com/dp/ASIN/ref=nosim?tag=YOURASSOCIATEID.

What is missing. The tag itself. It is an account credential, so it cannot be looked up, guessed or inferred - inventing one would attribute sales to a stranger's account.

How to discover it. The account holder reads it from Associates Central and supplies it. There is no other route.

Q-T50-03

Which marketplace is this campaign for?

open

Q-T50-04

Is the site already approved into the Associates program?

open

What we know. Amazon publishes review criteria for new applications - a site with substantial original content that is generally recent, and a guideline of at least ten posts.

What is missing. Whether an application has been made, is pending, or has been approved. No Associates ID exists anywhere in this repository, which is consistent with 'not yet' but does not prove it.

How to discover it. Owner checks Associates Central, or applies; the review outcome is visible only inside the account.

Q-T50-05

Which commission band applies to each of the three ASINs?

open

What we know. Table 1 fixes Kitchen at 4.50% and All Other Categories at 4.00%. All three listings sit under Home & Kitchen > Kitchen & Dining > Small Appliances > Fryers > Air Fryers.

What is missing. The rate field for the individual ASIN. A browse path is navigation, not the rate classification; only the account or an authenticated API response states it.

How to discover it. Read it per ASIN from the Associates account or from a Creators API response once credentials exist.

Q-T50-10

Does this project have a host that can run code, or only GitHub Pages?

open

What we know. The site is currently served from GitHub Pages, which serves static files and runs no application code.

What is missing. Whether a back end is available or planned. It determines whether click tracking, scheduled re-verification and an automated publishing pipeline are possible at all.

How to discover it. Owner decision. GitHub Actions can cover scheduled jobs without a server; click tracking needs somewhere to receive the event.

Q-T50-11

How often should the official sources be re-read?

open

What we know. This pass re-read every load-bearing source on 2026-11-16 and found one drift: the 26-quart Emeril listing's stored Amazon title is no longer the title Amazon serves. The program policies page states its own update date (2026-04-14) and the Operating Agreement states its (2025-10-15), so drift is detectable when a page states a date.

What is missing. A decision on cadence, and a scheduled runner to enforce it.

How to discover it. Owner sets the cadence; a GitHub Actions schedule can then run the existing verifiers and fail on drift.

Q-T50-12

Is the automation in the brief in scope now, or after the content proves out?

open

What we know. The brief asks for automated product research, trend detection, pricing and competition analysis, content generation, link management, click and conversion tracking and continuous optimisation. The research and scoring modules exist in the repository and are data-gated: they return 'insufficient data' rather than a guess.

What is missing. Sequencing. Every one of those modules needs the Associates credential and, for anything live, a host.

Q-T50-07

May this site display star ratings and review counts?

answered

What we know. Only from content Amazon serves through its API. The ratings visible on a product page may not be republished from a plain fetch. No API credential exists, so the cells stay blank.

What is missing. The credential. The rule itself is settled.

How to discover it. Register for the Creators API - it replaced the deprecated PA-API 5.0 - and read ratings from an authenticated response.
