How to use this page

A decision can only be made reasonably when the information behind it is known. This register lists the questions that are still open, what is known today and where that came from, what is missing, which decision the missing piece blocks, and how to obtain it. Nothing here is answered by inference: where no official source states a value, the row says so.

  1. Start with the answer these first list — four questions that unblock the rest.
  2. Work down the register in priority order.
  3. Record the answer against the question, and move it to the suggestions if it changes a recommendation.

These four are the ones that other answers depend on. Each is a question for the account owner rather than a research task.
