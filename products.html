How verification works

  1. Each supplied identifier is checked against the official Amazon product page (amazon.com/dp/<code>).
  2. The code format is checked against Amazon's official ASIN definition (unique 10-character alphanumeric code).
  3. Cross-checks are run against search indexes (Google, Bing), the Wayback Machine capture index, and the CamelCamelCamel Amazon US price tracker.
  4. A field is filled only when confirmed from an official source. Unconfirmed fields are left blank and the row is flagged.

To activate research on these products, re-supply each identifier as an exact 10-character ASIN taken directly from the Amazon product page URL (the string after /dp/) or from the product's Product Information section.
