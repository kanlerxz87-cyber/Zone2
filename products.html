1 · The supplied codes, exactly as supplied

Each supplied code is 9 characters, an Amazon ASIN is 10, and amazon.com/dp/<code> returns Amazon's Page Not Found page. No product attribute can therefore be stated for the token itself — which is why the cells that describe the code are blank and the row is marked unverified.

2 · What each supplied link resolves to — observed 2026-11-14

Each link.amazon URL resolves to exactly one Amazon product page, reproducibly. The decisive control: an unknown 9-character code on the same service returns a 404 (“You've clicked on an invalid URL”) instead of a product, so the supplied codes are honoured lookups rather than ignored tokens (flag F-20). What is still unconfirmed is the contract — no public Amazon document binds a link.amazon code to a product — so these are published as “the product this link resolves to”, never as “the product the brief named” (flag F-03).
