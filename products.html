Three short links in. Three listings out. The evidence in between.

The engagement supplied three link.amazon short links. Each resolves, reproducibly, to one live Amazon listing in the Air Fryers category. This page keeps the two sides of that finding separate: what the codes can prove as supplied, and what the destinations establish — with every row linked to the official page it was read from.

Two questions, kept apart on this page: what can be stated about each code as supplied, and what each link actually resolves to. Nothing is merged across that line, and every value that could not be confirmed from an official source is left blank.

The supplied codes, exactly as supplied

Each supplied code is nine characters — an Amazon ASIN is ten — and amazon.com/dp/<code> returns Amazon’s Page Not Found page for each. No product attribute can therefore be stated for the token itself, which is why those cells are blank and the row is marked unverified.

What each supplied link resolves to — observed 2026-11-14, re-observed 2026-11-15

Each link.amazon URL resolves to exactly one Amazon product page, reproducibly. The decisive control: an unknown nine-character code on the same service returns a 404 instead of a product, so the supplied codes are honoured lookups rather than ignored tokens (flag F-20). What remains unconfirmed is the contract — no public Amazon document binds a link.amazon code to a product — so these are published as “the product this link resolves to,” never as “the product the brief named” (flag F-03).

Per-product identity statement

Each product, with both statuses shown side by side: unverified as a brief item, observed as a link destination. The supplied short link is cited, not embedded as a purchase link — Amazon’s Program Policies treat an intermediate redirect that forwards the customer as a disqualifying link, so only the canonical destination is linked.

Verified specifications — each row sourced

Every row was read on 2026-11-14 from the official Amazon listing (“About this item” bullets and the Product-information block) or from the manufacturer’s own product page. Where two official pages disagree, the row is marked Conflict and shows both values with their sources; nothing is resolved by inference.
