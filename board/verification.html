The gate run

What enforces the numbers above

Every count on this page is re-derived when the page is written, and four gates replay against the tree. This page deliberately does not print the result of the last run. One of those gates rebuilds this page and compares it to a fresh render, so a page that quoted its own checker's verdict would be comparing itself against a run that had not finished — and a single failure would latch the page stale forever. The verdict belongs to the run: it is recorded in board/data/measured.json and enforced by .github/workflows/pages.yml, which will not publish a tree that fails.
