Amazon's own definition, read live 2026-11-17, and a control run on the same date.

BQ2-01 unanswerable-here

Is 'shopnow047c-20' an issued, active Associates ID belonging to this account?

What we have
It is the first tracking ID any brief for this project has supplied. It matches the shape Amazon publishes for a special-link tag: the application-review page gives the example 'abcd-20' (BD-13). **Since this question was recorded, session `7264f3c2` applied it** — 15 of 184 pages now carry the owner's tracking ID (shopnow047c-20) as a link parameter, the first real tag in the repository. That is an action taken elsewhere; it is recorded here because a reader of this row would otherwise believe nothing had happened.
What we do not
Whether the account exists, is enrolled, and is in good standing; whether this string is the ID that account was issued.
Answer
empty — the information does not exist yet
How to close it
Sign in to Associates Central and read the ID from the account. It cannot be checked from any public page: Amazon states the ID is 'automatically generated when you apply for the Associates Programme' (BD-12), so there is no public register to look it up in.
Who can close it
owner — one sign-in, no code
Cost of leaving it open
Every product link on the site stays unattributable, and the 15 links that now carry the tag cannot be confirmed to attribute to this account. RQ-22 cannot start.
