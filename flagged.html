How these were produced

The method behind the register:

  • Every table value was checked against the official source linked in its row.
  • Where a value could not be confirmed from an official source, the cell was left blank — values were never inferred or filled in.
  • The link-code / ASIN mismatch was detected by resolving each provided link.amazon short link and fetching the destination product page directly.
  • The reading of those links was settled by a control: an unknown nine-character code on the same short-link service returns a 404 instead of a product (F-20), which shows the supplied codes are honoured lookups. The full control trail is on the Products page.
  • Nothing on this page blocks the site. The items marked owner: user are the decisions only you can make — chiefly confirming the brief mapping (F-03) and supplying tagged links (F-24).
