How these were produced

  • Every table value on this site was checked against the official source linked in its row.
  • Where a value could not be confirmed from an official source, the cell was left blank — values were never inferred or filled in.
  • The code/ASIN mismatch was detected by resolving each supplied link.amazon short link and fetching the destination product page directly — re-done live on 2026-11-15 with identical results.
  • The reading of those links was settled by controls: an unknown code on the same service returns a 404 (F-20), and a valid 10-character ASIN fed to the same service also returns a 404 (F-28), so the supplied codes are honoured short-link lookups, not truncated ASINs.
